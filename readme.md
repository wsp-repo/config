Работа с кофигами через YAML-файлы.

Порядок чтения файлов (настройки последовательно перекрываются):
- /config.default.yml - в корне сервиса (где файл package.json)
  Файл с базовыми настройками по умолчанию, входит в состав репозитория и содержит минимальный набор настроек со значениями по умолчанию, необходимый для запуска сервиса

- /config.{NODE_ENV}.yml - в корне сервиса (где файл package.json)
  Файл для переопределения базовых настроек, не входит в состав репозитория, может использоваться локально для разработки, а также для запуска на прод-окружении с заданными параметрами. **Внимание!** Для NODE_ENV = "prod" или "production" считывается файл без суффикса (config.yml).

- {APP_CONFIG_YAML} - полный путь к файлу включая расширение
  Файл для переопределния настроек, не входит в состав репозитория, выполняет роль предыдущего этапа с тем отличием, что этот файл может иметь любое место размещения и имя. Может использоваться при запуске сервиса в рамках контейнеризации, когда файл настроек нельзя создать/подключить с заданным именем в корень проекта.

Использование пакета через прямой вызов методов:
  const value = getYamlString(jsonPath, options);

Использование пакета через декораторы:
class Config {
    @YamlString(jsonPath, options)
    public config!: string;
}

Параметр jsonPath - это строка в классическом формате указания JSON-Path путей в объекте:
  Для детального ознакомления https://github.com/JSONPath-Plus/JSONPath

Параметр options - набор опций для считываемого значения (все опции необязательные):
- required: true - флаг обязательности значения
- schema - кастомная схема валидации в формате AJV для проверки значения
- defValue - значение по умолчанию, если параметр отсутствует в конфигах (при наличии схемы валидируется)
- noValid - стратегия поведения при наличии некорректного значения в конфиге
  - YamlNoValid.Error - выдать исключение несоответствия значения (по умолчанию)
  - YamlNoValid.Default - использовать значение по умолчанию
- arrayMerge - стратегия слияния массивов при наложении опций конфигов
  - YamlMerge.Overwrite - перезаписать массив полностью (по умолчанию)
  - YamlMerge.Combine - комбинировать массивы по индексам
  - YamlMerge.Append - склеить все массивы в один
